# ShopSmart E-Commerce Website

A React-based E-Commerce Web Application developed using React JS and Vite.

## Features

- User Registration
- User Login
- Product Search
- Category Filtering
- Shopping Cart
- Quantity Management
- Payment Simulation
- Order Confirmation
- Order History
- Local Storage Persistence
- Responsive UI

## Technologies Used

- React JS
- JavaScript
- HTML
- CSS
- Vite

## Installation

Run the following commands:

```bash
npm install
npm run dev
